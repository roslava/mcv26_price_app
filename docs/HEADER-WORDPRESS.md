# Шапка раздела «Услуги и цены»

Изменения внесены в локальный проект /home/akdev/projects/mcv26/mcv26_price_app.
Архив mcv26-price-header.zip содержит только изменённые файлы приложения с сохранением путей.

Перед загрузкой сохраните резервную копию соответствующих файлов на хостинге.
Распакуйте архив в корень приложения, где находятся public/ и src/. Не загружайте его содержимое в корень WordPress.

Файлы:
- public/index.php — подключение компонента.
- src/View/site-header.php — разметка шапки, меню и окон.
- public/assets/site-header.css — оформление и адаптивность.
- public/assets/site-header.js — закрепление меню, бургер, раскрытие подменю.
- public/assets/site-logo.png, Inter-400.ttf, Inter-600.ttf, Inter-700.ttf — локальные ресурсы.

Текущий раздел определяется через AppUrl, поэтому сохраняются настройки MCV26_PUBLIC_BASE_PATH.
Внешние пункты меню ведут на https://mcv26.ru/.
Кнопка «Получить консультацию» открывает телефоны отделений. Форма WordPress с отправкой заявки не переносилась.
Поиск, цены, база данных и админка не изменены.
tests/PublicIndexPresentationTest.php обновлён в проекте под новую шапку, в архив загрузки не входит.

Проверено: PHP-синтаксис, поиск, подменю, окно консультации, мобильное меню, закрепление, ширины 375/800/1280.
PHPUnit: 166 тестов, 60 пропущено, две ошибки существовали до изменения:
testPublicHeroAndFooterCopyAndHomeLinks и testSectionNavigationIsSidebarAroundMainPriceContent.
